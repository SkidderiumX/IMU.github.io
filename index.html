InjectMyau

InjectMyau is a Minecraft client based on OpenMyau, with injection support for Lunar and Badlion clients. This site hosts changelogs and tracks the latest GitHub release.

File layout

To publish a file, add it to the matching folder in the site repository. The route pages pick it up automatically.

beta/dll/          -> /beta             (beta DLL download)
beta/changelog/    -> /betachangelog   (beta changelog .txt)
release/dll/       -> /release          (release DLL download)
release/changelog/ -> /releasechangelog (release changelog .txt)
